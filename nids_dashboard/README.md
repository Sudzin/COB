# NIDS SOC Admin Dashboard

Локальная админ-панель мониторинга сетевого трафика поверх обученного автоэнкодера (`autoencoder.keras` + `scaler.pkl` + `config.json`) и `tshark.exe`.

## Что внутри
- **`server.py`** — бэкенд на FastAPI + WebSocket: читает живой трафик через `tshark.exe`, считает 14 признаков за 1-секундное окно, прогоняет через обученный автоэнкодер, раскладывает пакеты по 6 обособленным протоколам, отслеживает сетевые потоки и умеет анализировать `.pcap` / `.pcapng` дампы.
- **`static/index.html`** — веб-интерфейс (работает полностью офлайн, без CDN и сборки):
  1. **Мониторинг Live** — графики MSE и скорости, 6 отдельных мини-окон по протоколам (`TCP`, `UDP`, `QUIC`, `DNS / mDNS`, `ICMP`, `ARP / Прочее`), цветной журнал событий в стиле Wireshark, лента тревог нейросети с объяснением топ-3 признаков.
  2. **Состояние сети и потоки** — направления трафика (`LOCAL / OUT / IN`), таблица активных потоков (`откуда -> куда`, порты, флаги), топ портов и живой вектор из 14 признаков (`факт vs реконструкция автоэнкодера`).
  3. **Анализ дампов (.pcap / .pcapng)** — загрузка любого дампа перетаскиванием или запуск готовых файлов из папки `test/` в 1 клик с той же аналитикой + экспорт отчёта в CSV.
- **`start.bat`** — запуск в один клик на Windows с автоматическим открытием браузера.

## Быстрый старт (Windows)

1. Распакуй папку `nids_dashboard` внутрь `G:\Мой диск\СОВ_НЕЙРОНКА\Данные\` (рядом с папками `model` и `test` — сервер найдёт их автоматически).
2. Один раз доустанови 3 веб-пакета (TensorFlow, scikit-learn, joblib, pandas и numpy у тебя уже стоят):
   ```powershell
   cd "G:\Мой диск\СОВ_НЕЙРОНКА\Данные\nids_dashboard"
   py -3.12 -m pip install -r requirements.txt
   ```
3. Запусти двойным кликом **`start.bat`** или из PowerShell:
   ```powershell
   py -3.12 server.py --open
   ```
4. В браузере откроется `http://127.0.0.1:8000`:
   - Выбери свой Wi-Fi адаптер (например, `5. Беспроводная сеть`) и нажми **«Старт Live»**.
   - Для демонстрации преподавателю без реальной атаки можно включить **«Демо-режим»** и нажимать кнопки инъекции (`SYN-скан`, `ICMP-флуд`, `UDP-флуд`).
   - Во вкладке **«Анализ дампов»** можно в 1 клик прогнать `Port_Scan_Causes_Wireshark_Crash.pcapng` из папки `test/`.
